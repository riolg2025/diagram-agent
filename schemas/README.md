# Schemas

This directory will contain the stable schema contracts for V0.1.

Expected schema areas:

- `evidence.schema.json`
- `semantic.schema.json`
- `intent.schema.json`
- `question.schema.json`
- `diagram-ir.schema.json`
- `validation.schema.json`

The current files are draft contracts. They are intentionally small and centered on the first end-to-end chain:

```text
Evidence -> Semantic Claim -> Intent Claim -> Diagram IR -> Validation Result
```
