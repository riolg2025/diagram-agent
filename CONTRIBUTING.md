# Contributing

This project is currently in the V0.1 Spec stage.

Contributions should keep the project evidence-grounded and schema-centered.

## Guidelines

- Keep observed evidence separate from inferred meaning.
- Prefer explicit hypotheses over hidden assumptions.
- Preserve provenance for important claims.
- Avoid committing to implementation details before the relevant schema or concept is stable.
- Keep documentation changes aligned with the current project vocabulary.

## Current Focus

The first useful contributions are:

- Refining core concepts.
- Defining initial schemas.
- Designing small benchmark examples.
- Clarifying the agent loop and confidence gate.
